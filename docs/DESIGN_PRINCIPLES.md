# Cognora Design Principles

## Never

- Task manager
- To-do list app
- Obsidian clone
- Notion clone
- Cyberpunk aesthetics
- Flashy animations
- Giant graph views

## Always

- Calm
- Premium
- Spatial
- Cognitive
- Continuity-first
- Thought-centric

## Philosophy

Thoughts are living entities.

The feed represents a cognitive field.

Relationships should be felt before they are explained.
